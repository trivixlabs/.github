# Trivix Labs

Open-source software by [Vitor Trigo](https://github.com/vitaomt) and [Rodrigo da Vitoria](https://github.com/rodrigovixc), from Brazil.

## Projects

| Project | What it does |
|---|---|
| [Quilate](https://github.com/trivixlabs/quilate) | Crypto portfolio tracker with a daily verdict per coin: hold, reduce or exit. A local backend, a dashboard and a macOS notch app. It only reads, and it never trades. |

## Contribute

Issues and pull requests are welcome, in English or Portuguese. A good place to start is the list of [good first issues](https://github.com/trivixlabs/quilate/labels/good%20first%20issue) in Quilate.
